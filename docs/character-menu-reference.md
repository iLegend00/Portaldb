# Character Menu Reference

Source: in-game screenshots supplied by the site owner on 2026-08-18.

## Structure
The Character menu contains three scrollable tabs:
- Stats
- Skills
- Titles

The left-side Profile/Combat Stats panel remains visible while switching tabs.

## Profile fields visible
- Character name
- Race
- Level
- Job/Class
- CP
- EXP Bonus
- EXP progress

## Combat Stats fields visible
- Max HP
- Max MP
- HP/s
- MP/s
- DEF
- MDEF
- P.ATK
- M.ATK
- Crit Rate
- Crit Dmg
- Dmg Up
- Ign DEF

Additional combat-stat rows exist below the visible scroll area and are awaiting manual transcription.

## Base Stats tab
The right-side Stats panel shows six base attributes and their listed effects:
- STR — P.ATK
- VIT — Max HP, DEF, HP/s
- AGI — Move Spd, Atk Spd, Crit Rate
- DEX — Crit Rate/Dmg, Cast Spd
- INT — Max MP, M.ATK, MP/s
- WIS — MDEF, M.ATK, MP/s

The panel also shows remaining Status Points and a Reset action.

## Skills tab
Skills are presented as scrollable entries containing, where applicable:
- Skill name / rank suffix
- Skill level
- Skill type / damage type
- Target type
- Range
- MP cost
- Cooldown
- Damage/scaling
- Status effects or other behavior

Visible examples in the supplied screenshot include Cripple I, Bash I, Blunt Mastery I, and Body Slam I.

## Titles tab
Titles are presented as scrollable entries with:
- Title name
- Stat bonuses
- Equip / Unequip control

The current game rule from v1.1.12 allows only one title to be equipped at a time.

## PortalDB implication
This reference defines the canonical field names PortalDB should use for character/build-planner data. Do not infer additional hidden combat-stat rows until they are transcribed or captured in-game.
