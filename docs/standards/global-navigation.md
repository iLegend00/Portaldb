# Global Navigation Standard

**Status:** Active  
**Scope:** Every user-facing PortalDB page

PortalDB's global primary navigation is limited to:

- **Database** → `database.html`
- **Walkthrough** → `walkthrough.html`
- **Tools** → `tools.html`

The PortalDB brand is the global Home control and links to `index.html`; Home is not duplicated in the primary navigation.

Feature and category destinations belong inside their relevant hubs rather than being repeated globally. Database records and factual content use Database as their active parent. Build Planner, Crafting Calculator, and Item Finder use Tools. The homepage has no active primary-navigation item.
