# Global Navigation Standard

**Status:** Active  
**Scope:** Every user-facing PortalDB page

PortalDB's global primary navigation is limited to:

- **Home** → `index.html`
- **Database** → `database.html`
- **Walkthrough** → `walkthrough.html`
- **Tools** → `tools.html`

The PortalDB brand also links to `index.html`. Keeping both the linked brand and the explicit Home navigation item is intentional.

Feature and category destinations belong inside their relevant hubs rather than being repeated globally. Database records and factual content use Database as their active parent. Build Planner, Crafting Calculator, and Item Finder use Tools. The homepage uses Home as its active primary-navigation item.
