# PortalDB Canonical NPC Portrait Masters

These eight PNG files are the **only canonical NPC portrait source images** for PortalDB.

Codex instructions:

- Use only the PNG files in this folder as portrait source artwork.
- Do not substitute, regenerate, redraw, or select older NPC art from elsewhere in the repository.
- Web-ready derivatives may be created from these masters (for example WebP), but the artwork itself must not be altered.
- Preserve transparency.
- Keep Breda's existing working presentation/layout as the reference implementation for all NPC portrait pages.
- `manifest.json` records dimensions, byte sizes, and SHA-256 hashes for integrity checks.

Canonical files:

- `arlette.png`
- `breda.png`
- `eren.png`
- `hogan.png`
- `leaf.png`
- `neria.png`
- `rendall.png`
- `theron.png`
