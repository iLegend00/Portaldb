# PortalDB Canonical Artwork

This directory is the canonical home for original PortalDB artwork going forward.

## Structure
- `home/category-cards/` — canonical source art for the seven homepage category cards.
- Future artwork should be organized under logical subfolders here (for example `home/`, `npcs/`, `items/`, `locations/`, `ui/`, `decor/`).

## Rules for Codex
1. Treat files in this directory as approved PortalDB source artwork.
2. Do not substitute old generated alternatives, cropped mockup fragments, or unrelated art.
3. Preserve transparent backgrounds where present.
4. For production use, create optimized derivatives under `assets/` (prefer WebP where appropriate) while keeping these source masters unchanged.
5. Do not overwrite a source master unless explicitly instructed.
