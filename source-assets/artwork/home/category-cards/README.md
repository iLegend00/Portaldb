# Homepage Category Card Masters

Approved canonical artwork for the PortalDB homepage category cards.

- `items.png` — sword, treasure chest, adventurer loot
- `quests.png` — quest scroll, quill, field-guide book
- `npcs.png` — friendly fantasy field-guide character / NPC representation
- `bosses.png` — dark gray/near-black werewolf inspired by Lycaros; red-orange eyes; no armor
- `crafting.png` — alchemy/crafting workshop objects
- `builds.png` — blue/gold magical build-planning compass/rune emblem
- `locations.png` — parchment fantasy map and compass

All seven use transparent backgrounds and are intended to sit over the parchment/book treatment of the homepage cards. Do not bake card frames, labels, or buttons into these images.
